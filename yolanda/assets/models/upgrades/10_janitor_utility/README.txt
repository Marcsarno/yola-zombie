JANITOR UTILITY

Meters. GLB Y-up. Individual props have local floor-center or explicit wall bottom-center pivot. All component meshes and materials are editable in the separate source file. Assemblies do not include presentation platforms. See manifest.json for exact measured triangles, bounds, materials, anchors and suggested placements. These are game-art props, not construction or accessibility plans.

IMPORT AND PERFORMANCE
Each asset has a named root at its declared pivot. Static components are joined into one mesh, typically one paint primitive plus optional metal/light primitives. The mobile materials use glTF COLOR_0 vertex colors, so use the imported glTF material or enable vertex colors when replacing it. There are no image textures. The few independently moving parts (cubicle doors and toilet lids) have named hinge parents; rotate those locally, not their mesh children. No animation clips, collision meshes, accessibility certification, or game integration are included.

Assemblies use the same individual props, placed for a catalog comparison. They are not navigation-tested room layouts. Listed placement clearances are suggestions. For a gameplay room, place walls first and use the individual props with your actual character envelope.

Blender sources are in the separate SOURCE archive. All GLBs were reimported into clean Blender scenes; the measured import audit is included. The preview is a Blender render of these asset builds.
