# Current visual pass

Autonomous patients and generic staff use the user-supplied Gray Patient 04, Older Patient 02 and Patient Hair 03/04 rigs, adapted in Blender 4.3.2. Source creators/licenses were not identified in the upload; no third-party commercial-license claim is made. The user explicitly authorized their modification and use in this project. The eight edited variants, 20-joint rig conventions, measured triangle counts and file hashes are in `assets/blender/people/manifest.json`. Original source archives are retained locally and are not published as downloads. Main character Yolanda remains separately authored.

Plants, cabinets, windows, lamps and wall artwork in this pass are original project models built in Blender; see `assets/blender/Hospital-Ambience-Manifest.json`. All UI icons and Web Audio sounds are original. Approved uploaded medical GLBs remain unchanged; their existing manifest is `public/models/uploaded/ASSET_MANIFEST.json`.

## Earlier Blender rebuild

The October 8, 2026 equipment rebuild created original project geometry authored and exported in Blender. The complete editable source is `assets/blender/Yolanda-Hospital-Library.blend`; provenance and per-asset triangle counts are in `assets/BLENDER_MANIFEST.json`.

Two Point Hospital is a broad style reference only. No proprietary game assets, characters, interfaces or layouts are used. Yola is a custom character based on the user-provided likeness reference. Fictional prep machines, hand items, interface and synthesized sounds are original project work.
